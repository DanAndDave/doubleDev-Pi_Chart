# Section numbering

`numberedHeadings(concept)` gives one label per entry of cardSections, in the same order.

- A section with a heading is numbered. Only headed sections count, from 1. The number is written in lowercase roman numerals, then `) `, then the heading: `i) Definition`, `ii) Rationale`, `iv) Examples`.
- From the 11th headed section on, the number is written in plain digits instead: `11) Appendix`.
- The preamble, the section with no heading, is labelled `*) preface`. It takes no number.
- A `##` heading is numbered exactly like a `#` heading.
